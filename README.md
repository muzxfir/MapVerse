# 🌍 MapVerse

MapVerse is a modern interactive world map website built with React and Vite.

## Features

- Interactive world map
- Search countries
- Country flag and details
- Capital, population, area, currency and languages
- Dark/light mode
- Mobile responsive design
- Direct Google Maps link
- No API key required

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Upload the project to GitHub.
2. Open Vercel.
3. Import the GitHub repository.
4. Keep the default Vite settings.
5. Click Deploy.

## APIs

- REST Countries API
- World Atlas TopoJSON

## Live map

This version includes OpenStreetMap using React Leaflet. Selecting a country moves the map and displays a marker.
